Factory Inventory Management System

Architecture Overview · Vue 3 + FastAPI demo application

System Architecture

Browser Client Vue 3 SPA · localhost:3000
→
HTTP / REST Axios · CORS enabled
→
FastAPI Server Uvicorn · localhost:8001
→
JSON Files In-memory at startup

Tech Stack

Frontend

Vue 3.4 Composition API Vite 5 Vue Router 4 Axios Custom SVG Charts

Backend

Python 3.11+ FastAPI 0.110 Pydantic v2 Uvicorn uv (package mgmt)

Data & Tooling

JSON files In-memory store pytest httpx (test client) i18n (en / ja)

Data Flow

1. User Interaction Filter changes, navigation
→
2. useFilters composable Shared reactive state
→
3. api.js Builds query params
4. HTTP GET ?warehouse=&category=&month=
→
5. FastAPI Endpoint apply_filters() in main.py
→
6. Pydantic Validation response_model typed
7. Vue refs updated allOrders, inventoryItems
→
8. Computed properties Derived metrics, charts
→
9. Template renders Reactive UI update

Application Structure

Frontend Views (client/src/views/)

  • Dashboard.vue — Overview & KPIs
  • Inventory.vue — Stock by warehouse
  • Orders.vue — Order tracking
  • Spending.vue — Finance analytics
  • Demand.vue — Forecasts
  • Backlog.vue — Backorder monitoring
  • Reports.vue — Reports view

Composables (client/src/composables/)

  • useFilters.js — Global filter state
  • useAuth.js — Auth state
  • useI18n.js — Translation helper

Backend Data (server/data/)

  • inventory.json
  • orders.json
  • demand_forecasts.json
  • backlog_items.json
  • spending.json / transactions.json
  • purchase_orders.json

Filter Dimensions

  • warehouse — Multi-warehouse filter
  • category — Product category
  • status — Order status
  • month — Month or quarter (Q1-2025)
